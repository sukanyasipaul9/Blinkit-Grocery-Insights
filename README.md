📊 Project Overview

This Power BI project, “From Cart to Checkout: Blinkit Grocery Insights,” provides an interactive and comprehensive view of Blinkit’s grocery data. It analyzes sales trends, outlet performance, product visibility, and customer ratings to support data-driven business decisions.

The dashboard visualizes key metrics such as total sales, average rating, number of outlets, and product visibility, enabling users to identify high-performing stores and popular item categories.

🎯 Key Insights & Features

Total Sales: ₹1.20M overall grocery sales.

Average Rating: 3.92, reflecting customer satisfaction.

Item Analysis: 1559 items analyzed for visibility and sales contribution.

Outlet Reach: 8523 outlets across Tier 1, Tier 2, and Tier 3 locations.

Sales by Outlet Type: Comparison among Grocery Stores and Supermarket Types 1, 2, and 3.

Sales by Item Type: Highlights top-selling categories like Fruits, Snacks, and Dairy.

Item Visibility Analysis: Identifies how visibility influences sales.

Interactive Slicers: Filters for outlet size (Small, Medium, High) and outlet type for detailed analysis.

🧠 Purpose

This dashboard was designed to help Blinkit and similar businesses gain meaningful insights from operational data. It allows stakeholders to:

Track revenue performance by outlet and item type.

Discover top-performing product categories.

Analyze visibility impact on product sales.

Make strategic decisions using real-time, interactive visuals.

🛠 Tools & Technologies

Microsoft Power BI – Dashboard creation and visual analytics

Microsoft Excel / CSV – Data preprocessing and cleaning

📈 Outcome

The final dashboard offers a clear, engaging, and interactive experience, combining visuals and KPIs for actionable grocery business intelligence. It enhances decision-making by providing a unified view of Blinkit’s operational data.
